Spindle

The full editing experience of a commercial office suite, as forever-free React libraries you own.

MIT licenceReact + TypeScriptSheets · Docs · SlidesYjs collaboration

Open Spindle ↗Source on GitHub ↗

The problem

For years I wanted an encrypted drive of my own: somewhere to keep spreadsheets, documents and decks without handing them to someone else's cloud. When I finally started building it, I hit a wall. There was no open source library that offered full-featured editors for all three.

What existed was either heavy and bloated, covered only one document type, or came with proprietary or mixed licensing. Every path led back to renting your editor from somebody else.

If the editor isn't yours, the document isn't really yours either.

What Spindle is

Spindle is a set of React libraries for spreadsheets, documents and slides. You drop an editor into your app, hand it JSON, and get JSON back. Where that JSON goes is your call.

  • Sheets: virtual scrolling, keyboard navigation, a formula engine with 146 functions, dynamic arrays and topological recalculation, and sparse storage that only keeps non-empty cells.
  • Docs: true page layout with line-level pagination, rich text, headers and footers with dynamic fields, tables, images and undo history.
  • Slides: text, shapes, images, connectors and tables, 60fps drag, resize and rotate with smart guides, themes, layouts and a presenter view.

How it's built

Each editor is split into a core package (the engine and data model) and a react package (the UI). Rendering is canvas-first, which keeps large sheets fast and bundles small.

Collaboration runs on a Yjs CRDT that the library owns internally. You bring the transport: Spindle ships an in-memory and a WebSocket provider, plus IndexedDB persistence so edits survive a refresh or going offline. Because sync payloads are opaque bytes, end-to-end encryption is a thin wrapping layer, not a rewrite.

npm install @b32nio/spindle-sheets-core @b32nio/spindle-sheets-react

Where it's going

Spindle is the foundation for that encrypted drive, and for anyone else who wants office-grade editing without the lock-in. Help is very welcome, especially on performance, new features, and ports to other frontend frameworks.
